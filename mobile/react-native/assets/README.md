# Asset Placeholder

This directory should contain:

## Images

- `icon.png` (1024x1024) - App icon
- `splash.png` (1242x2436) - Splash screen
- `adaptive-icon.png` (512x512) - Android adaptive icon
- `favicon.png` (192x192) - Web favicon

## Instructions to Add Assets

1. Create these images using a design tool (Figma, Adobe XD, etc.)
2. Use the Motion colors:
   - Primary: #008B8B (Teal)
   - Accent: #FF8C00 (Orange)
3. Place files in this directory
4. Reference them in `app.json`
